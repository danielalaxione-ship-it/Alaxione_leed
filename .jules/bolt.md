## 2023-10-27 - Playwright Playbook: dynamic waits and text_content vs inner_text
**Learning:** Playwright's `inner_text()` has a high performance cost because it forces CSS layout calculation and verifies visibility for every call. Changing to `text_content()` reads directly from the DOM and skips layout checks, saving significant overhead in loops. Also, static waits (`wait_for_timeout`) are extremely wasteful. Replacing them with dynamic waits for the main element (`wait_for_selector`) reduces scrape time substantially, dropping it from ~2m25s down to ~1m5s for 25 items in this repo.
**Action:** Default to `text_content()` over `inner_text()` when visibility checks are not strictly required. Always eliminate static timeouts in favor of dynamic waits based on target element presence.
