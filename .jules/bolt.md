## 2024-05-24 - Optimizing Playwright DOM Interactions in Google Maps Scraper

**Learning:** When scraping dynamic apps like Google Maps that load heavily customized DOMs (hidden elements, dynamic rendering), using `.inner_text()` triggers Playwright's layout checks for element visibility. This forces synchronous style recalcs and layout operations across the entire DOM tree, taking considerable CPU time on a large DOM. Also, static waits inside a loop cause compounding performance issues; whereas replacing them with sequential dynamic waits might time out if elements are optional. A better pattern for dynamic pages with optional elements is a specific dynamic wait for a required main element followed by `wait_for_load_state('domcontentloaded')` or an overall safe fast timeout.

**Action:** Replaced `.inner_text()` with `.text_content()` for text extraction to bypass layout visibility checks. Replaced the static 3s wait (`page.wait_for_timeout(3000)`) inside the per-place scraping loop with `page.wait_for_selector('h1.DUwDvf', state='attached', timeout=5000)` followed by `page.wait_for_load_state('domcontentloaded')`. This ensures we wait only as long as necessary for the DOM to settle before doing synchronous `.count()` checks, reducing scraping time by over 50% without risking race conditions.
